# App Store / Google Play readiness checklist

Apple: bundle identifier, signing profile, privacy manifest, camera/location/notification explanations, icons, launch screen, privacy/support URLs, account deletion, screenshots, review test account.

Google Play: package name, upload signing, Data Safety form, permission disclosures, screenshots, feature graphic, privacy/account deletion URLs, internal testing track.

No store account, certificate, publication or paid service is created in this phase. Real-device camera, GPS, push and background behavior remain to be tested.
